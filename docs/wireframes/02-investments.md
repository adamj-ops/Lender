## Key Notes

1. **Simplified Investment Flow**: 3 steps max - Term → Amount → Fund

2. **Smart Defaults**: Pre-select recommended term based on investor goals

3. **Proactive Maturity**: Alert 90 days before maturity, prompt for preference

4. **Visual Progress**: Progress bar shows exactly where each note stands

5. **One-Click Reinvestment**: Make rolling notes frictionless

---

## Data Requirements

| Field | Source | Update Frequency |
|-------|--------|------------------|
| Note Status | Database | Real-time |
| Payment Progress | Payment service | Daily |
| Maturity Date | Note terms | Static |
| Monthly Payment | Calculation | Static |
